## ISEF Computational Biology (CBIO) harsh review: 20 weaknesses + exact additions

Based on the manuscript: provenance-first Chagas public-data compendium, ordinal severity model, miRNA discovery, cross-compartment validation. 

---

# 1. Weakness: Computational novelty is not strong enough

**Judge criticism:**

> “This is a rigorous pipeline, but where is the new computational method?”

Current strength is reproducibility, not algorithmic innovation.

### Add:

Create a formal **Provenance-Aware Omics Discovery Framework**.

Benchmark:

Traditional GEO workflow vs your workflow:

* metadata errors detected
* sample mismatches found
* missing annotations recovered
* reproducibility failures prevented

Turn engineering into a measurable method.

---

# 2. Weakness: CORE6 module is circular

The paper admits:

> the module uses the same cohort for selection and evaluation. 

### Add:

**Nested bootstrap discovery validation**

Every bootstrap:

1. resample patients
2. select miRNAs again
3. run novelty filter
4. rebuild module
5. evaluate held-out samples

Report:

* miRNA selection frequency
* held-out c-index
* confidence interval

---

# 3. Weakness: No external severity validation

The model is cross-validated on one severity cohort. 

### Add:

Leave-one-cohort-out biological validation:

Measure:

* pathway preservation
* target-network preservation
* direction agreement

Not necessarily severity prediction.

---

# 4. Weakness: ML benchmarking is limited

Current comparisons:

* clinical baseline
* single miRNA baseline

### Add:

Compare:

* elastic net
* random forest
* XGBoost
* SVM
* gradient boosting
* ordinal regression

Same:

* folds
* seeds
* preprocessing

---

# 5. Weakness: No strong null model

A judge may ask:

> “Could this happen randomly?”

### Add:

Run 1000 permutations:

* shuffled labels
* shuffled miRNA identities
* random feature sets

Show observed performance exceeds null distribution.

---

# 6. Weakness: Feature stability unknown

A model can perform well but select unstable features.

### Add:

Report:

* bootstrap feature frequency
* CV fold recurrence
* permutation importance

Example:

“miR-1 appeared in 94% of discovery runs.”

---

# 7. Weakness: Compartment specificity claim could be post-hoc

Current:

18/20 cardiac replication, 6/20 blood replication. 

### Add:

Create:

**Cross-compartment conservation score**

For each miRNA:

Serum → cardiomyocyte → blood → heart tissue

Calculate agreement.

Compare against random matched miRNAs.

---

# 8. Weakness: Blood replication is phenotype-mismatched

Blood may not measure the same biological state.

### Add:

Do pathway-level comparison:

Instead of asking:

“Do the same miRNAs appear?”

Ask:

“Do the same biological pathways appear?”

---

# 9. Weakness: miRTarBase popularity bias

Validated databases favor famous miRNAs.

### Add:

Matched controls:

Random miRNAs matched by:

* target number
* publication count
* expression level

Test enrichment against these.

---

# 10. Weakness: Target validation depends on one database

### Add:

Cross-database confirmation:

Compare:

* miRTarBase
* TargetScan
* miRDB
* miRWalk

Use experimentally validated evidence separately.

---

# 11. Weakness: Drug target analysis is weak translational evidence

Open Targets/druggability is interesting but generic. 

### Add:

Specificity analysis:

Are these targets:

* Chagas-associated?
* cardiac-remodeling associated?
* uniquely enriched?

Not just “druggable.”

---

# 12. Weakness: Calibration is poor

The manuscript notes ranking works but probability calibration is weak. 

### Add:

Calibration methods:

* isotonic regression
* Platt scaling

Report:

* calibration slope
* Brier score
* reliability curve

---

# 13. Weakness: No decision utility analysis

A high c-index does not equal usefulness.

### Add:

Decision curve analysis:

Compare:

* age/sex model
* miRNA model
* combined model

---

# 14. Weakness: Batch effects may influence results

Public datasets have technical variation.

### Add:

Sensitivity:

Run:

* with batch correction
* without batch correction

Report whether conclusions change.

---

# 15. Weakness: Severe group is relatively small

The severe group has limited power.

### Add:

Robustness tests:

* leave-severe-out
* influence analysis
* outlier detection
* jackknife analysis

---

# 16. Weakness: No comparison to standard biomarker pipelines

### Add:

Compare against:

* differential expression only
* PCA clustering
* random forest feature selection
* limma/DESeq2-style workflows

Show why your framework is superior.

---

# 17. Weakness: Literature novelty filtering may miss hidden overlap

The manuscript acknowledges residual possibility from incomplete source literature access. 

### Add:

Expand novelty screening:

* full-text mining where available
* citation network search
* automated similarity search

---

# 18. Weakness: Biological mechanism remains associative

The paper identifies regulatory modules, not causation.

### Add:

Causal prioritization:

Rank candidates by:

* direction consistency
* network centrality
* tissue agreement
* disease pathway proximity

Avoid causal wording.

---

# 19. Weakness: Reproducibility is excellent but not demonstrated externally

### Add:

Blind reproduction test:

Give pipeline to another person/machine.

Measure:

* same outputs?
* same figures?
* same hashes?

This would impress CBIO judges.

---

Current paper includes:

* compendium

* miRNAs
* targets
* druggability

### Add:

Choose one central CBIO claim.

Best:

> “A provenance-first computational framework improves reliability and reproducibility of public omics biomarker discovery.”

Everything else becomes validation.
